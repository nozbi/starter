# Starter
A Laravel starter project providing a base for application development.

## Features

- **SPA-like navigation**
- **Built-in authentication**
- **Styled application shell**
- **Centralized routes and navigation menu configuration**

## Technologies Used

- **Laravel (`laravel/framework`)** – PHP framework
- **Livewire (`livewire/livewire`)** – SPA like navigation
- **Jetstream (`laravel/jetstream`)** – Authentication and auth pages
- **Uikit (`nozbi/uikit`)** – Application shell and routing

## Installation
1. Copy the starter project into your desired project destination.
2. Install PHP dependencies:

   ```bash
   composer install
   ```
